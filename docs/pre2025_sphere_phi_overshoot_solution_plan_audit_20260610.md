## Audit of the User-Provided Analysis

### Confirmed: the frames are not static theoretical equilibrium

The existing 0-to-200000 segment is a wetting relaxation process, not a static
solution. The apparent global circle-fit angle and cap-height error continue
to change strongly:

Conclusion:

```text
The case must not be used as a static contact-angle reproduction. It is only
an exploratory relaxation diagnostic.
```

### Corrected: the sphere initializer has not lost a 0.5 factor

The active source initializes a diffuse sphere with:

```text
PhaseF = 0.5*(PhaseField_h + PhaseField_l)
       - 0.5*(PhaseField_h - PhaseField_l) * BubbleType
         * tanh(2 * (Ri - Radius)/IntWidth)
```

For `PhaseField_l=0`, `PhaseField_h=1`, and droplet `BubbleType=1`, this is
the expected bounded `0..1` diffuse-sphere formula. The direct VTI audit also
shows the fluid phase field is bounded:

```text
step     fluid phi max
0        0.999999800
50000    0.999999825
100000   0.999999818
150000   0.999999737
200000   0.999999601
```

Conclusion:

```text
The observed global phi_max > 1 is not caused by a missing 0.5 in the fluid
sphere initializer.
```

### Confirmed and refined: phi overshoot exists, but it is a wall/boundary ghost issue

The global `phi_max` is physically unacceptable if interpreted as a fluid
phase-field value, but the refined audit locates it entirely on boundary
cells:


Conclusion:

```text
The leading defect is not bulk fluid PhaseField overshoot; it is wall/solid

shows that the observed overrun is generated by the normal geometric wall
branch itself, not by the sphere initializer or VTI output corruption. Special
boundary fallback remains a separate risk, but it is not the direct source of
the audited phi>1 cells.
```

### Confirmed: free-sphere initial geometry is too far from theta030 cap equilibrium

The initial droplet is a diffuse sphere tangent to the solid sphere. For a
theta030 cap-on-sphere equilibrium, the liquid should already intersect and
wet the solid over a finite contact patch. Therefore the initial condition is
far from the target equilibrium even if the fluid phi field itself is bounded.

Conclusion:

```text
The current case mixes two effects: a poor initial geometry for low-angle
static wetting and a wall ghost phase overrun. A theoretical-cap initializer is
needed before judging whether the contact-angle law itself is quantitatively
wrong.
```

This chain is more specific than the initial "global phi_max is wrong"
interpretation because it separates fluid phase from ghost/boundary phase.

## Audit of the Solution Plan

### Risk 1: treating boundary phi>1 as automatically nonphysical

Boundary ghost values can mathematically lie outside fluid 0..1 in some
boundary schemes. Therefore the gate is not simply "boundary phi must never
exceed 1"; the real gate is:

```text
Does boundary phi>1 feed GradPhi/mu/surface force and correlate with shape
drift/mass drift?
```

Mitigation:

```text
Stage 3 instruments wall path values and Stage 2 compares flat/curved and
free/cap initial geometry.
```

### Risk 2: theoretical cap initializer may hide wall BC defects

A near-equilibrium initializer can reduce transient drift without fixing the
underlying wall ghost issue.

Mitigation:

```text
Always compare free-sphere and cap initial geometries, and require boundary
phi diagnostics in both.
```

### Risk 3: clean-source lane may differ from current patched lane in unrelated ways

The current local patches are default-off for PRE XMLs, but generated code and
setting tables differ.

Mitigation:

```text
Run a one-frame or short smoke in both lanes with identical XML and compare
step-0 fluid/boundary phi audit before long runs.
```

### Risk 4: clamp diagnostic can become an undocumented tuning shortcut

Mitigation:

```text
Clamp builds must have a distinct model/binary name and report a visible
claim limit. Clamped results cannot be used for validation or paper figures.
```

### Risk 5: large full 230 x 230 x 400 cases could waste GPU time

Mitigation:

```text
All gates above use reduced or short cases first. Full-size cases are blocked
until field-health and wall-path diagnostics pass.
```
