## 3. The time-length confound (must be resolved)

```text
Doc 25:  M=0.1 t150 = 150.09 deg, "essentially exact"  <- but only 1500 steps
14C-2:   M=0.3 t150 = 152.73 deg, drift +0.243/1k      <- 12000 steps
14C-2b:  M=0.2 t150 = 152.68 deg, drift +0.228/1k      <- 12000 steps
```

The M=0.1 "pass" is not comparable: 1500 vs 12000 steps. At a drift of even
+0.1 deg/1k, 1500 steps would move t150 by only ~0.15 deg — within noise — while
12000 steps would move it by ~1.2 deg. So a slow drift that is invisible at 1500
steps becomes visible at 12000. **The t150 drift may have been present at M=0.1
all along; doc 25 simply did not run long enough to see it.**

This means the mobility comparison that drove doc 28's "fall back from 0.3" is
**not apples-to-apples**. Before choosing any working mobility, run:

```text
14C-2c-CONFIRM:  M=0.1 equilibrium 30/90/150 @ 12000 steps
gate: same as 14C-2b (|err|<0.5 all, t150 drift<0.05/1k)
```

Outcomes:
- If M=0.1 @ 12000 steps ALSO drifts on t150 -> the drift is NOT a mobility
  effect; it is a long-time geometry/phase-field effect present at all M. Then
  dropping M is pointless, and the real fix is elsewhere (see section 4).
- If M=0.1 @ 12000 steps holds t150 (<0.5 deg, low drift) -> there IS a mobility
  threshold somewhere in (0.1, 0.2), and the binary search should target it.

## 4. What the diagnostics say about the drift source (informational)

From the per-step diagnostics on t150 @ M=0.2:

```text
WettingPathId on the contact-line band:  ALL nodes = 0  (not 30, not -30)
footprint radius: shrinking 10.82 -> 9.49 over 12000 steps
liquid volume:     ~stable 17300 -> 17172 (mass drift only +0.11%)
theta:             rising 150 -> 152.7
```

Reading:
- **WettingPathId = 0 on the whole clband** at equilibrium. At init=bc the
  droplet is already at the target, so the compact solve has no de-pinning
  residual to write — the ghost is stable (path 0 = no update needed). This is
  different from the decoupled cases (path 30) where the line is moving. So the
  t150 drift is NOT driven by compact-ghost write activity. The ghost is idle.
- **Footprint shrinking while theta rises** is self-consistent: the obtuse cap
  is slowly contracting its base and steepening, drifting away from 150 toward a
  slightly higher (more upright) angle.
- **Liquid volume stable** rules out mass loss as the cause.

So among the three candidate sources (mobility diffusion / cap-fit artefact /
compact-ghost static error), this run's evidence points AWAY from active
compact-ghost behavior (path=0) and toward a slow interface relaxation that the
150° geometric pin does not fully arrest over long times. Whether mobility
controls its rate is exactly what 14C-2c-CONFIRM will test.

This avoids a wasteful "drop M, still drifts, drop M again" loop. One 12000-step
M=0.1 equilibrium run (3 cases, ~13 min) settles the confound.
