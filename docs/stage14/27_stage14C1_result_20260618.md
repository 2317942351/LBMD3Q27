Diagnostic deliverable of Stage 14C-1. Runs the existing solver binary with
**only the mobility M varied**, all dynamic layers OFF, compact-write ON. No
wetting-physics source change. The sweep tests whether the slow decoupled
contact-line response (Stage 14A/14C-prime) is mobility-limited.

## 0. Headline

```text
Mobility IS a real limiter (Situation A), but with a mild parallel cost
(Situation B trend). Stencil dilution (ghost_frac_tan ~0.16) is independent
of M, confirming the 14C-prime prediction that dilution is structural.

=> Raise M (0.3-0.4 is the useful range), THEN re-evaluate whether the
   remaining gap still needs Layer D. Do not implement Layer D yet.
```

### Read-outs

- **Contact-line speed rises with M.** For 60→30 the asymptotic slope goes
  −0.22 (M0.1) → −0.56 (M0.4): **2.5x faster**. For 120→150: +0.52 → +0.74.
  M=0.3 gives the biggest single jump (−0.22 → −0.48); M=0.4 adds a bit more.
- **θ_end improves:** 60→30 reaches 54.8° at M0.4 vs 58.2° at M0.1; 120→150
  reaches 128.1° vs 125.3°. Still short of target (30/150) at 12k, but the
  slope is still nonzero, so longer runs would close more.
- **RMS grows with M** (0.48 → 0.65 for 60→30). Mild Situation B: the droplet
  contour gets rougher as M rises. But max|U| is nearly flat (bulk |U| ~6e-5
  in all cases), so the RMS growth is interface deformation, not a velocity
  blow-up.
- **Mass drift** stays under 1% for all M (worst −0.81% at M0.4 60→30). The
  drift grows slowly with M but is acceptable.

- **ghost_frac_tan is ~constant in M (0.154-0.186).** Confirms Stage 14C-prime:
  stencil dilution is structural, not mobility-dependent. Raising M does not
  fix the dilution; it just speeds up the (diluted) drive.
- **bulk |U| ≈ 3-10x contact-line |U|** at every M (14C-prime Q3 holds).
  Spurious current stays in the bulk; raising M does not move it to the
  contact line.
- **Fs_radial weakens slightly with M** (closer to equilibrium → smaller
  residual), self-consistent.

## 4. Decision-tree verdict

Applying the user's tree:

```text
M raises contact-line speed significantly (2.5x at M0.4 for 60->30)
AND RMS grows but is interface-deformation, not velocity blow-up
AND mass drift < 1%
  => Situation A with a mild Situation-B flag.
  => Mobility is a real lever. Raise M to 0.3-0.4.
  => Do NOT implement Layer D yet. Re-measure at the chosen M with a longer
     run; only if the slope plateaus far from target does Layer D become
     warranted (and even then, only as the residual compensator for the
     ~0.16 ghost_frac_tan dilution).
  => The mild RMS growth does NOT need a Layer-D fix (Layer D is contact-line
     local; RMS is bulk). If RMS must be controlled later, that is a separate
     force-balance / sigma / IntWidth diagnostic, run in parallel, not bundled.
```

## 5. Recommendation for 14C-2

Pick **M = 0.3** (best speed/cost balance: the big slope jump is at 0.1→0.3;
M0.4 adds little more speed but more RMS and mass drift). Run equilibrium
30/90/150 at M=0.3 to confirm the static angle is preserved (14C-2):

```text
M=0.3, equilibrium 30/90/150, 12000 steps, compact write, layers OFF
gate:
  equilibrium |theta_measured - theta_target| < 0.5 deg (was <0.15 at M0.1)
  mass drift < 1%
  RMS_end not more than 2x the M0.1 equilibrium RMS
```

If equilibrium still passes at M0.3, M0.3 becomes the working mobility for the
long decoupled runs and (eventually) curved-surface work. If equilibrium
degrades, fall back to M0.2.

## 6. What this does NOT settle

- Whether the residual gap to target (θ=30 vs measured 54.8 at M0.4/12k) closes
  with a longer run, or needs Layer D. The nonzero slope at 12k suggests more
  of it is kinetics than dilution, but only a longer run (24k-50k) at the
  chosen M will tell. Defer the Layer-D decision until that run.
- Curved-surface behavior (sphere/cylinder). Not touched; deferred to 14F.
- The bulk RMS mechanism. Confirmed bulk, not contact-line, but its root cause
  (F_surf vs F_pressure balance, force-iteration convergence) is a separate
  diagnostic not run here.
