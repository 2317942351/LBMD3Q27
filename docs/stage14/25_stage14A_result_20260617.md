## 0. Headline (read this first)

**The Stage 14A evidence overturns the premise of Stage 14B.**

The plan's §2.4-2.5 claimed the compact `q_s` solve is "rejected/clamped on
25-81% of the target wall" and made that the blocking cause of the slow
decoupled response. Per-node decomposition shows this is **misleading**:

```text
Every WettingPathId = -30 rejection lies in the PURE-PHASE wall region,
where q_f ~= 0 (gas) or q_f ~= 1 (liquid).
In the CONTACT-LINE BAND (0.05 <= q_f <= 0.95) — the region that actually
drives the contact angle — WettingPathId = 30 (compact write SUCCESS) is
100.0% on every case, every timestep audited.
```

So the compact solve is **healthy exactly where it must be**. The 25-81%
"rejection" is the solver correctly refusing to manufacture a ghost value in
pure-phase wall cells, where the contact-angle relation has no meaningful
solution and the neutral fallback is physically correct.

**Consequence:** Stage 14B ("fix the compact solve rejection") is no longer the
next step — there is no defect to fix in the contact-line band. The slow
decoupled response must come from elsewhere (mobility, stencil dilution, or
geometry). The plan ordering must be revised (see §5).

This correction is recorded honestly. The first-pass H3 reading (below) was
real but incomplete; the contact-line-band split is what reverses the
conclusion.

## 4. Physical interpretation

When the three fluid-side vertices all lie in the pure gas (q_f ≈ 0), the
contact-angle relation

```text
(q_f - q_s)/D = -(4/W) cos(theta) q_w (1 - q_w),   q_w = (d_s q_f + d_f q_s)/D
```

with q_f ≈ 0 forces q_w ≈ (d_f/D) q_s, and the only roots that satisfy the
relation lie far outside [0,1]. There is no physically meaningful ghost value
there, because **there is no interface at that wall cell to bound q_s**. The
solver correctly returns `reason=7` and writes the neutral ghost (path=-30).

This is not a bug. It is the correct behavior of a compact-stencil solver
invoked outside its domain of validity (the diffuse interface). The audit's
`target_wall_csq_valid_fraction` statistic (0.188-0.654) was counting these
physically-irrelevant pure-phase cells as failures, which inflated the apparent
problem.

### What about wall_ghost_clamp_fraction ≈ 0.71?

That number (from the morphology metrics) is the same effect viewed through a
different field: `WallGhostClampHit` fires on the pure-phase cells where the
ghost is clamped to the neutral midpoint. It is not a sign of a broken solve
at the contact line. It is consistent with §3.

### Why then is the decoupled response slow?

The compact ghost is doing its job at the contact line. The slowness must come
from one of (the order is a hypothesis to test, not a conclusion):

```text
(a) Mobility M = 0.1 is low, limiting contact-line diffusion speed.
(b) The compact ghost enters the 26-point gradPhi stencil at only 1-3 of 26
    neighbours, so the contact-angle signal is diluted into gradPhi/mu/F_surf.
    (doc 23 root-cause argument — still viable, now the leading candidate.)
(c) Circle-fit RMS grows 50-80x over 12k steps: spurious currents or interface
    oscillation may be opposing the contact-line motion.
```

These are exactly what Stage 14C (M sweep) and a stencil-dilution / spurious-
current diagnostic should address. They are NOT a compact-solve defect.

## 5. Revised stage ordering

The original 14A->14B->14C chain assumed 14B was mandatory. It is not.

```text
14A  diagnose rejections                         [DONE — see this doc]
14B  fix the compact solve rejection coverage    [CANCELLED — no defect in clband]
14C  mobility M sweep on the (already-healthy) compact drive   [NOW NEXT]
14C' NEW: stencil-dilution + spurious-current diagnostic
       (measure how much of the contact-angle ghost signal reaches F_surf)
14D  Layer D GNBC, only if 14C/14C' show inadequate drive
14E  Layer C Ju (residual-form), last resort
14F  curved surfaces after flat-wall closure
```

14C and 14C' are independent and can run together. Both reuse the existing
binary — no wetting-physics change, just different case parameters (M sweep)
and additional post-processing (dilution/current measurement).

### What 14B would still legitimately address (optional, low priority)

The flat 187-node `reason=9` (no clean all-fluid triangle) spike that is
constant across all cases is a real, fixed-geometry edge artifact at the
FlatLowerY patch boundary. It does not affect the contact line and is not
worth a wetting-physics change. It can be revisited during 14F curved-surface
work if the same artifact appears there.
