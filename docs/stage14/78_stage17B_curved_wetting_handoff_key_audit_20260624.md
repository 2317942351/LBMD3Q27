## Why The Curved-Wall Route Changed

The likely curved-wall failure chain is:

```mermaid
flowchart LR
    A["Analytic cylinder/sphere geometry"] --> B["Staircase solid mask"]
    B --> C["Jagged wall normal"]
    B --> D["Sharp-mask ghost or PhaseF path"]
    C --> E["Discontinuous near-contact-line n_s"]
    D --> F["Near-wall gradPhi spikes"]
    E --> G["Contact angle measurement drift"]
    F --> H["Local surface-force / body-force spikes"]
    G --> I["Droplet leakage or pinning"]
    H --> J["NaN or nonphysical overshoot"]
```

The direct implication is that the core Stage17B target is not a new local `q_w(theta)` tweak. The target is a coherent geometry-to-boundary chain:

```text
signed distance d(x)
diffuse solid psi_s = 0.5 * (1 - tanh(d / (sqrt(2) * eps_s)))
grad psi_s
smooth solid-to-fluid normal n_s
bounded shadow ghost
write permission only inside a guarded near-wall band
```
