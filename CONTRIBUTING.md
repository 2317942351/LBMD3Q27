# Contributing

This repository is public for audit, not for community development.

External direct commits are not accepted. Unsolicited pull requests may be
closed without merge. Reviewers should provide findings as issues, external
review reports, or line-referenced comments.

The project owner controls all changes to the canonical repository.

TCLB source files included here preserve the upstream GPLv3 license. This
repository policy controls collaboration on this canonical repository only; it
does not revoke rights granted by GPLv3 for upstream TCLB code.
